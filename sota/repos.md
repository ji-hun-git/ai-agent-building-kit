# Reference repositories

Verified 2026-10-28 against the GitHub API (exists, not archived, recent activity). Licenses as reported by GitHub.

- **License column.** `NOASSERTION` means GitHub found a license file it could not match to a single SPDX identifier (often dual, custom or source-available terms); `none detected` means GitHub found no license file. Read the repository's own license before reusing code.
- **Activity.** Every repository below was pushed to in 2025-06 or later, except one canonical reference that is marked as such in its row. Renamed or moved repositories are listed under their current name, with the old name noted.
- **Borrowed here.** "Skill" is this kit's `building-ai-agents` skill; "Template" is the kit's small reference harness. "—" means the repository is listed as a resource only. Where the template deliberately leaves a part out (durable execution, a search service, an exporter, a web UI), the row says which repository fills that gap.

## How to choose

- **Claude is the primary model and the loop runs in your process** → start from [anthropics/claude-agent-sdk-python](https://github.com/anthropics/claude-agent-sdk-python) (or its TypeScript twin) and the closest app in [anthropics/claude-quickstarts](https://github.com/anthropics/claude-quickstarts).
- **OpenAI-first, or approvals arrive hours after the request** → [openai/openai-agents-python](https://github.com/openai/openai-agents-python); add [temporalio/sdk-python](https://github.com/temporalio/sdk-python) once runs must survive restarts.
- **The deployment target is a cloud platform** → Google Cloud: [google/agents-cli](https://github.com/google/agents-cli) with ADK (not agent-starter-pack for new projects); AWS: [strands-agents/harness-sdk](https://github.com/strands-agents/harness-sdk) with [awslabs/agentcore-samples](https://github.com/awslabs/agentcore-samples); .NET or Azure: [microsoft/agent-framework](https://github.com/microsoft/agent-framework).
- **Provider-neutral, with explicit control flow** → [langchain-ai/langgraph](https://github.com/langchain-ai/langgraph), plus [langchain-ai/deepagents](https://github.com/langchain-ai/deepagents) when the harness pieces should come ready-made and [langchain-ai/agent-chat-ui](https://github.com/langchain-ai/agent-chat-ui) for a UI.
- **Exposing your own system to agents** → [modelcontextprotocol/python-sdk](https://github.com/modelcontextprotocol/python-sdk) or the TypeScript SDK, built to revision 2026-07-28 and checked with [modelcontextprotocol/inspector](https://github.com/modelcontextprotocol/inspector); a coding agent for editors goes over [agentclientprotocol/agent-client-protocol](https://github.com/agentclientprotocol/agent-client-protocol).
- **RAG over company documents** → [docling-project/docling](https://github.com/docling-project/docling) for parsing, [pgvector/pgvector](https://github.com/pgvector/pgvector) or [opensearch-project/OpenSearch](https://github.com/opensearch-project/OpenSearch) for hybrid retrieval with permissions enforced in the engine, and [vibrantlabsai/ragas](https://github.com/vibrantlabsai/ragas) metrics on a golden set; add [OSU-NLP-Group/HippoRAG](https://github.com/OSU-NLP-Group/HippoRAG) or [HKUDS/LightRAG](https://github.com/HKUDS/LightRAG) only when that set shows many multi-hop questions.
- **An eval gate in CI** → [UKGovernmentBEIS/inspect_ai](https://github.com/UKGovernmentBEIS/inspect_ai) for sandboxed agent tasks or [promptfoo/promptfoo](https://github.com/promptfoo/promptfoo) for declarative cases and red-team scans; shortlist models with the benchmark that matches the agent's shape ([sierra-research/tau2-bench](https://github.com/sierra-research/tau2-bench), [eval-sys/mcpmark](https://github.com/eval-sys/mcpmark), [harbor-framework/terminal-bench](https://github.com/harbor-framework/terminal-bench), [scaleapi/SWE-bench_Pro-os](https://github.com/scaleapi/SWE-bench_Pro-os)), then decide on your own suite.
- **Self-hosting open-weight models** → [vllm-project/vllm](https://github.com/vllm-project/vllm) or [sgl-project/sglang](https://github.com/sgl-project/sglang) on one node; [llm-d/llm-d](https://github.com/llm-d/llm-d) or [ai-dynamo/dynamo](https://github.com/ai-dynamo/dynamo) from two replicas up; [LMCache/LMCache](https://github.com/LMCache/LMCache) when multi-turn KV outgrows GPU memory.
